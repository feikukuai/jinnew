江湖金手指 · 交付包使用说明

现实任务 → 兑换点 → 武功。把现实中的坚持，练成江湖里的绝学。

一、交付包内容

目录文件说明
app/江湖金手指.apk伴侣 App（任务 / 兑换点 / 金手指分配 / Mod 管理）
mod/诗酒芳华录-金手指版.zip已注入金手指的《诗酒芳华录》Mod 包（jy_ry.xml + jy_ry_mod + jy_ry_maps）
game/base-2.apk游戏本体《群侠传，启动！》（com.jynew.wuxia_launch）
tools/goldenfinger.lua
inject_mod.py
dump_bundle.py		金手指脚本与注入工具，用于给其它 Mod 注入金手指
根目录使用说明.html本文件

二、快速上手（四步）

1
装游戏
安装 game/base-2.apk（若已装可跳过）。
2
装 Mod
把 mod/诗酒芳华录-金手指版.zip 解压，得到 jy_ry.xml、jy_ry_mod、jy_ry_maps 三个文件， 放进手机的 /storage/emulated/0/jynew/mods/jy_ry/ 目录。
若你已经装过《诗酒芳华录》，只需用本包内的 jy_ry_mod 覆盖原文件即可。
3
装 App 并授权
安装 app/江湖金手指.apk，首次打开后在「设置」页点「授予『所有文件访问权限』」。 没有这个权限，App 无法读写 Mod 目录和账本。
4
开始联动
在 App「任务」页设定现实任务并完成 → 获得兑换点 → 在「金手指」页把兑换点分配到武功， 或到「兑换游戏资源」换银两 / 物品 / 历练。然后进入游戏，金手指会在读档时自动兑现。

三、App 使用说明

任务页

  • 习惯可反复完成，点 ✓ 加分，点 − 撤销并回收兑换点。
  • 日常每天只能打卡一次，跨天自动重置。
  • 待办一次性任务，完成后置灰。
  • 奖励消耗兑换点兑换的「现实奖励」（如看一集电视剧），只扣分不产出。
  • 顶部四张卡：兑换点余额 / 已投入武功 / 累计获得 / 累计消耗。

金手指页

  • 顶部显示可分配兑换点；每门武功按等级曲线消耗兑换点，可随时、分多次投入，不必一次用完。
  • 点 +50 / +100 / 全部投入 分配；投入即写入账本，供游戏内读取。
  • 武功等级曲线：升到下一级所需兑换点 = 100 + (当前等级-1) × 50，最高 10 级。

兑换游戏资源

  • SILVER 换游戏内银两、ITEM 换物品、EXP 给主角加历练。
  • 兑换消耗的是 App 里的兑换点；实际发放发生在游戏内（进入游戏 / 读档时）。

设置页

  • 显示账本路径、待下发指令数，可「立即导出账本」。
  • 游戏内进度：显示从游戏存档导出的主角面板（等级 / 气血 / 内力 / 攻击 / 防御 / 银两 / 武功数 / 物品数）。

四、数据交换原理

App 与游戏通过手机存储里的两个文件通信，金手指 Mod 会随游戏自动读写它们：

方向文件作用
App → 游戏ledger.luaApp 写出的账本（Lua 表）。记录兑换点余额、武功等级、待发放指令。游戏读档时读取并兑现，兑现后自动清空。
游戏 → Appstate.json金手指 Mod 把主角「角色面板 + 包裹 + 武功」导出为 JSON，App 在设置页读取展示。

两个文件的目录（App 与 Mod 完全一致，两个位置都会写）：

/storage/emulated/0/jynew/goldenfinger/
/storage/emulated/0/Android/data/com.jynew.wuxia_launch/files/goldenfinger/

账本 ledger.lua 长这样：

return {
  version = 1,
  points = 100,
  skills = { { name = "降龙十八掌", category = "外功", level = 3, exp = 250 } },
  pending = {
    { kind = "SKILL",  skill = "降龙十八掌", level = 3 },
    { kind = "SILVER", amount = 1000 },
    { kind = "ITEM",   item = 123, amount = 1 },
    { kind = "EXP",    amount = 200 },
  },
}

五、给其它 Mod 注入金手指

金手指需要注入到 Mod 的 hotfix 脚本里（该脚本随 Mod 被游戏预加载）。用 tools/ 里的脚本即可：

# 1) 先看看这个 Mod 包里有没有 hotfix
python dump_bundle.py <mod包>

# 2) 注入金手指，输出为新文件（原文件不动）
python inject_mod.py <原始_mod包> <输出_mod包> goldenfinger.lua

输出文件名必须与 Mod 清单一致（例如 jy_ry.xml 对应 jy_ry_mod），替换到 /jynew/mods/<modId>/ 下即可。

工具需要 Python 3 与 UnityPy：pip install UnityPy

六、常见问题

进游戏后兑换点没到账？

  • 确认 jy_ry_mod 已替换为金手指版（原版没有金手指逻辑）。
  • 确认 App 已获得「所有文件访问权限」，且账本已导出（设置页可手动导出）。
  • 金手指在读档 / 主角数据初始化时兑现；进游戏读一次档即可。兑现后账本会被清空，属正常现象。
  • 兑换点的发放是「读档时结算」：同一批指令只会发放一次。

「游戏内进度」一直是空的？

  • 需要先进入游戏并读档，Mod 才会写出 state.json；回到 App 设置页点「刷新游戏数据」。

武功没升到对应等级？

  • 游戏内武功需要先「习得」才能设定等级；若该武功主角尚未学会，金手指会尝试学习它。请以游戏内实际面板为准。
  • 游戏版本差异可能导致个别字段名不同，属正常兼容范围。
备份提醒：替换 Mod 前建议备份 /jynew/mods/jy_ry/ 目录与你的游戏存档，以便随时回退。
