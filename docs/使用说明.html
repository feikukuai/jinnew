江湖金手指 · 交付包使用说明

现实任务 → 兑换点 → 武功。把现实中的坚持，练成江湖里的绝学。

一、交付包内容

二、快速上手（五步）

1
装游戏
安装 game/base-2.apk（若已装可跳过）。
2
装 Mod
把 mod/诗酒芳华录-金手指版.zip 解压，得到 jy_ry.xml、jy_ry_mod、jy_ry_maps 三个文件， 放进手机的 /storage/emulated/0/jynew/mods/jy_ry/ 目录。
若你已经装过《诗酒芳华录》，只需用本包内的 jy_ry_mod 覆盖原文件即可。
3
装 App 并授权
安装 app/江湖金手指.apk，首次打开后在「设置」页点「授予『所有文件访问权限』」。 没有这个权限，App 无法读写 Mod 目录和账本。
4
进游戏读一次档
先进入游戏、读取你的存档（任意槽位）。游戏内 Mod 会把该存档的角色面板、包裹、已学武功导出到 App。
回到 App「金手指」页点「刷新」，即可看到主角当前的武功与包裹；同页下方会列出可兑换的武功秘籍。
5
添加桌面小组件
长按手机桌面空白处 → 「小组件」→ 找到「江湖金手指」，把需要的组件拖到桌面。 共有 兑换点 / 任务 / 角色属性 / 已学武功 / 包裹 五种，点按任一组件即可打开 App。

三、App 使用说明

任务页（只做任务，赚兑换点）

  • 习惯可反复完成，点 ✓ 加分，点 − 撤销并回收兑换点。
  • 日常每天只能打卡一次，跨天自动重置。
  • 待办一次性任务，完成后置灰。
  • 奖励消耗兑换点兑换的「现实奖励」（如看一集电视剧），只扣分不产出。
  • 顶部「兑换点余额」卡片紧凑显示余额与累计获得 / 消耗 / 已投入。
  • 本页只负责赚取兑换点，不放置兑换入口；赚到的兑换点到「金手指」页花掉。

金手指页（花兑换点）

页面顶部固定显示兑换点余额与主角状态卡（可折叠），下方用页签切换「兑换」与「分配武功」两块内容，避免秘籍太多把分配区挤到很下面。

  • 主角状态（游戏内实时同步，可折叠）：显示当前存档槽位、主角名 / 等级、气血内力、银两；点右侧箭头展开后，可查看已学武功（含游戏内等级）与包裹物品（秘籍会标【秘籍】）。点任意条目可查看介绍与属性。默认收起，只显示一行摘要，不占屏幕。
  • 「兑换」页签：
    · 兑换武功秘籍：直接读取游戏内的真实秘籍目录（ItemType=2 的武功书），兑换后进游戏研读即学会对应武功；已学会的秘籍会显示「已学会」不可重复兑换。带秘籍搜索框，可按秘籍名或武功名筛选；默认只显示前 6 本，可点「展开全部」查看全部。点任意秘籍卡片可查看介绍与属性（秘籍说明、效果加成、所学武功的伤害类型 / 攻击范围 / 消耗内力、威力成长与学习门槛）。
    · 兑换游戏资源：银两、主角历练、神兵 / 物品。
  • 「分配武功」页签：这里只列出主角已在游戏内学会的武功。未学会的武功不会出现——需先在「兑换」页换取对应秘籍、进游戏研读学会后，才会出现在此列表。每门武功可随时、分多次投入兑换点，不必一次用完；分配后写入账本，进游戏读档即生效。带分类筛选与武功搜索框，可快速定位。
  • 武功等级曲线：升到下一级所需兑换点 = 100 + (当前等级-1) × 50，最高 10 级。

设置页

  • 顶部「快速上手」引导：五步说明安装、读档、做任务、兑换与生效流程。
  • 显示账本路径、待下发指令数，可「立即导出账本」。
  • 游戏内进度：显示从游戏导出的主角面板（含存档槽位），可「刷新游戏数据」。

桌面小组件

App 提供五种桌面小组件：长按手机桌面空白处 → 「小组件」→ 找到「江湖金手指」，把需要的组件拖到桌面即可； 组件可自由调整大小，点按任一组件会打开 App。

小组件显示内容
兑换点兑换点余额、累计获得 / 消耗、已投入武功、待下发指令数
任务任务总数与待完成数，按「未完成优先」列出任务（含类型与奖励 / 消耗）
角色属性主角名 / 等级、存档槽位、银两与历练、气血内力、攻击 / 防御 / 轻功、拳掌 / 御剑 / 耍刀 / 奇门 / 暗器、品德 / 声望 / 资质
已学武功主角已学会的武功与游戏内等级
包裹包裹中的物品与数量（秘籍会标注【秘籍】）
小组件在 App 内数据变化、或从游戏切回 App 自动同步时刷新；「角色属性 / 已学武功 / 包裹」需先进入游戏读档才有数据。

自动同步与误触保护

  • 从游戏切回 App 时会自动刷新角色数据、权限与游戏安装状态，无需手动点刷新。
  • 删除任务 / 武功 / Mod、清空指令、重置数据、恢复默认库等危险操作都会二次确认，避免误触丢失数据。

四、数据交换原理（游戏桥接 Mod 方式）

App 与游戏不直接改存档文件，而是通过手机存储里的两个文件通信，金手指 Mod 随游戏自动读写它们。 这样不同存档槽位的进度由游戏自己管理，App 只是「读面板、发奖励」。

方向文件作用
App → 游戏ledger.luaApp 写出的账本（Lua 表）：兑换点余额、武功等级、待发放指令。游戏读档时读取并兑现，兑现后自动清空。
游戏 → Appstate.json金手指 Mod 导出：archiveIndex（当前存档槽位）、player（角色面板 + 已学武功 wugongs + 包裹 items）、books（武功秘籍目录）、money。

两个文件的目录（App 与 Mod 完全一致，两个位置都会写）：

/storage/emulated/0/jynew/goldenfinger/
/storage/emulated/0/Android/data/com.jynew.wuxia_launch/files/goldenfinger/

账本 ledger.lua 长这样：

return {
  version = 1,
  points = 100,
  pending = {
    { kind = "SKILL",  skill = "降龙十八掌", level = 300 },  -- 武功等级 ×100
    { kind = "SILVER", amount = 1000 },                      -- 银两（物品ID=174）
    { kind = "ITEM",   item = 34, amount = 1 },              -- 秘籍/物品（34=罗汉拳书）
    { kind = "EXP",    amount = 200 },                       -- 主角历练
  },
}

五、给其它 Mod 注入金手指

金手指需要注入到 Mod 的 hotfix 脚本里（该脚本随 Mod 被游戏预加载）。用 tools/ 里的脚本即可：

# 1) 先看看这个 Mod 包里有没有 hotfix
python dump_bundle.py <mod包>

# 2) 注入金手指，输出为新文件（原文件不动）
python inject_mod.py <原始_mod包> <输出_mod包> goldenfinger.lua

输出文件名必须与 Mod 清单一致（例如 jy_ry.xml 对应 jy_ry_mod），替换到 /jynew/mods/<modId>/ 下即可。

工具需要 Python 3 与 UnityPy：pip install UnityPy

六、常见问题

进游戏后兑换点没到账？

  • 确认 jy_ry_mod 已替换为金手指版（原版没有金手指逻辑）。
  • 确认 App 已获得「所有文件访问权限」，且账本已导出（设置页可手动导出）。
  • 金手指在读档 / 主角数据初始化时兑现；进游戏读一次档即可。兑现后账本会被清空，属正常现象。
  • 兑换点的发放是「读档时结算」：同一批指令只会发放一次。

「金手指」页看不到可分配的武功？

  • 这里只显示主角已在游戏内学会的武功。请先进入游戏读档，再回 App 点「刷新」。
  • 若主角尚未学会任何武功：先到「金手指」页兑换一本武功秘籍，进游戏在包裹里研读学会，再回来刷新。

兑换了秘籍，包裹里没有？

  • 秘籍是通过账本指令在读档时发放的，需先进游戏读一次档。
  • 确认兑换的秘籍有合法的游戏物品 ID（秘籍列表由游戏内真实目录提供，正常情况都有效）。

「游戏内进度」一直是空的？

  • 需要先进入游戏并读档，Mod 才会写出 state.json；回到 App 点「刷新游戏数据」。
备份提醒：替换 Mod 前建议备份 /jynew/mods/jy_ry/ 目录与你的游戏存档，以便随时回退。
